## Question
7. What is *configuration drift* in an infrastructure context?

## Options
Option 1: A deviation between a system's current state and its documented or intended baseline configuration
Option 2: The gradual slowdown of a system due to accumulated software updates
Option 3: An unexpected increase in cloud resource costs over time
Option 4: The difference in configuration between two different deployment environments

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. Configuration drift is the divergence between what a system should look like (the baseline) and what it actually looks like at a point in time. Detecting and remediating drift is a core infrastructure reliability practice.

## Incorrect Answer Feedback
Drift is not about performance degradation, cost changes, or environment differences. It specifically means a system has diverged from its intended configuration baseline. The correct answer is Option 1.
