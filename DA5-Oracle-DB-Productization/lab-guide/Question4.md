## Question
4. You need to schedule a daily DBMS_STATS gather. Which Oracle facility is correct?:

## Options
Option 1: `DBMS_SCHEDULER` — the modern Oracle scheduler supporting schedules, programs, dependencies, and job management

Option 2: `DBMS_JOB` — the original Oracle scheduler with a simpler interface for creating and managing database jobs

Option 3: An OS-level cron job that invokes sqlplus -s to run scheduled `DBMS_STATS.GATHER_*` procedures

Option 4: A trigger on `sys.scheduler$_jobs` configured to execute maintenance-related tasks every 24 hours

## Answers
Option 1 : 1
