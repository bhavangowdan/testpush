## Question
3. Your RMAN script includes `BACKUP DATABASE PLUS ARCHIVELOG; DELETE NOOBSOLETE;`. What does `PLUS ARCHIVELOG` add, and why does it matter for a transactional ledger DB?:

## Options
Option 1: It backs up the listener configuration together with the database files for complete environment recovery

Option 2: It backs up archived redo logs along with the database files to support point-in-time recovery between full backups

Option 3: It backs up the alert log so backup activity can be matched with database errors and warnings

Option 4: It enables the backup to run across multiple channels in parallel to improve backup speed

## Answers
Option 2 : 1
